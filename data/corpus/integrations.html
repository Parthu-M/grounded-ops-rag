Nimbus Integrations.

Nimbus webhooks use HTTPS and send JSON request bodies. A webhook delivery is considered successful for any response status from 200 through 299. Failed webhook deliveries are retried after one minute, five minutes, 30 minutes, and two hours. Nimbus stops retrying after the fourth retry.

Every webhook request includes an X-Nimbus-Signature header computed with HMAC-SHA256. Receivers should calculate the signature over the unmodified request body and compare it using a constant-time function. Signing secrets can be rotated with a 24-hour overlap period.

The public API allows 600 requests per minute per organization. A rate-limited request returns status 429 and a Retry-After header measured in seconds. Pagination uses opaque cursor tokens, and clients must not parse or modify a cursor.
